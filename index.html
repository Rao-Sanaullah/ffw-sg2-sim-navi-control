One window to map and navigate the FFW-SG2 in simulation

A lightweight GUI for SLAM mapping, saving and loading maps, and Nav2 + AMCL navigation of the ROBOTIS FFW-SG2 in Gazebo. It's an add-on for the official ai_worker repository.

Features

Everything runs from one panel, so there are no terminals to juggle.

SLAM mappingLaunches Gazebo, the FFW-SG2, SLAM and RViz with one click.
Saved-map navigationRelaunches with Nav2 + AMCL on the map you select.
Map managementSave, list, load and delete maps with confirmation.
Manual drivePad or W/S, A/D, Q/E keys to /cmd_vel. Silent when idle, so it never fights Nav2.

Installation

This project contains only sim_control_panel.py and run_nav_sim.sh. Get ai_worker from the official repository.

# 1. Official ai_worker (branch jazzy)
git clone -b jazzy https://github.com/ROBOTIS-GIT/ai_worker.git

# 2. Add the two files to its root
cp sim_control_panel.py run_nav_sim.sh ai_worker/
chmod +x ai_worker/run_nav_sim.sh

# 3. Start and enter the container
cd ai_worker
./docker/container.sh start
./docker/container.sh enter

# 4. Inside the container (once)
apt-get update && apt-get install -y python3-tk
# Run the panel (inside the container)
export GZ_IP=127.0.0.1
python3 /root/ros2_ws/src/ai_worker/sim_control_panel.py

Tested with ai_worker 1.3.2 (jazzy).

Usage

Use the panel to control everything; RViz is for pose and goals; Gazebo is for watching.

1 · Create a map

  1. Press Start mapping (SLAM) and wait about 30–60 s.
  2. Click the panel and drive with W/S, A/D, Q/E.
  3. Map every area you need until it's white in RViz.
  4. Set a new name in Save to, e.g. …/maps/room1.
  5. Press Save Map while SLAM is still running, then ⟳.

2 · Navigate

  1. Pick the map in Load map.
  2. Press Start saved-map nav.
  3. In RViz, set 2D Pose Estimate where the robot is.
  4. Set a 2D Goal Pose on a white (free) area.
  5. To remove a map: Stop all, select it, then 🗑 Delete.

Troubleshooting

Logs are in /tmp/nav_sim_logs/.

ProblemFix
Gazebo world doesn't loadexport GZ_IP=127.0.0.1 before starting the panel.
Panel file not found in the containerStale mount: ./docker/container.sh stop, then start and enter.
Robot doesn't move after saved-map navExpected. Set 2D Pose Estimate, then 2D Goal Pose.
Failed to create planThe goal is unmapped or blocked. Pick a white cell or map that area first.
